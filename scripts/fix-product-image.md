# Image Editing Guide for pink-orange-product.jpg

## Quick Fix Instructions (Photoshop/GIMP/Photopea)

### 1. Fix Background (Most Important)
**Photoshop:**
- Open image
- Select → Subject (AI selection)
- Refine Edge → Feather: 0.5-1px
- Create new layer with pure white (#FFFFFF) background
- Place behind subject

**Alternative (Photopea - Free):**
- Use Magic Wand or Quick Selection
- Select background → Delete
- Add white layer behind

### 2. Straighten Image
- Use Ruler Tool (I key)
- Draw line along left edge of pouch
- Image → Image Rotation → Arbitrary
- Apply suggested angle
- Crop to remove transparent edges

### 3. Lighting & Contrast Adjustments
**Lightroom/Photoshop Camera Raw:**
- Exposure: +5 to +10
- Contrast: +10
- Highlights: -5
- Shadows: +5
- Clarity/Texture: +5

### 4. Make Label Pop
- Select label area (Rectangular Marquee)
- Filter → Sharpen → Unsharp Mask
  - Amount: 100-150%
  - Radius: 1-2px
  - Threshold: 0-2
- Adjustments → Levels
  - Whites: +5
  - Blacks: -5

### 5. Add Soft Shadow
- Duplicate subject layer
- Fill with black
- Blur: 15-20px
- Opacity: 10-15%
- Position slightly down and right
- Place behind subject

### 6. Crop for Web
- Aspect Ratio: 1:1 (square) or 4:5
- Leave breathing room around product
- Export as JPG, Quality: 90-95%

## Export Settings
- Format: JPG
- Quality: 90-95%
- Color Space: sRGB
- Dimensions: 2000x2000px (1:1) or 1600x2000px (4:5)
