# Pure Peel Co. Website Documentation

This folder contains all setup and configuration documentation for the Pure Peel Co. website.

## Documentation Files

- **README_ADMIN.md** - Admin dashboard setup and usage
- **README_ANALYTICS.md** - Google Analytics integration guide
- **README_CANADA_POST.md** - Canada Post shipping API setup
- **README_DOMAIN_SETUP.md** - Domain configuration guide
- **README_EMAIL_SETUP.md** - Email service configuration
- **README_EMAIL_TESTING.md** - Email testing instructions
- **README_RESEND_SETUP.md** - Resend email service setup
- **README_STRIPE_SETUP.md** - Stripe payment processing setup
- **CANADA_POST_SETUP.md** - Additional Canada Post setup details
- **QUICK_EMAIL_FIX.md** - Quick email troubleshooting guide

## Quick Start

1. Install dependencies: `npm install`
2. Set up environment variables in `.env` file
3. Start development server: `npm run dev`
4. Start backend server: `node server.js`

For detailed setup instructions, refer to the specific documentation files above.
